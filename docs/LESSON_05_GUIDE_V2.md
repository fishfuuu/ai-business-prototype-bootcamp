# 第五课学员操作指南 (GUIDE V2) — 工程 Harness 护栏与记忆机制

> **学习目标**：掌握原生 `/init` 指令配置 `CLAUDE.md` 工程 Harness (安全鞍具)，建立短期/中期/长期三分记忆模型与 S/L 存读档机制，彻底杜绝 AI 幻觉与规则遗忘。

---

## 💡 IT 跨界沟通术语卡：Engineering Harness (工程鞍具 / 物理护栏)

- **标准 IT 术语**：`Engineering Harness` (工程鞍具 / 物理护栏)
- **生活化通俗比喻**：**赛马的鞍具与缰绳** 🏇
  - 没有鞍具和缰绳的野马（AI Agent），跑得虽快但随时可能把骑手摔下马，或者跑偏方向。
  - 给马儿戴上鞍具（`CLAUDE.md` + 构建禁令），骑手（主管）才能精准把控方向，确保 AI 不脱轨。
- **IT 沟通场景**：“我们为项目部署了工程 Harness 护栏，物理锁定了包管理器与编码规则，确保 AI 生成的代码安全可控。”

## 🧠 三分记忆模型结构图

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 长期记忆 (Long-term)  ➔ CLAUDE.md                        │
│    - 物理存放在磁盘根目录                                    │
│    - 记录包管理器禁令、构建脚本与 4 大业务防错红线          │
├─────────────────────────────────────────────────────────────┤
│ 2. 中期记忆 (Mid-term)    ➔ LESSON_04_IMPLEMENTATION_PLAN.md│
│    - 记录 Step 1..N 的状态流转与 commit_sha                 │
├─────────────────────────────────────────────────────────────┤
│ 3. 短期记忆 (Short-term)  ➔ 对话窗口 Context Buffer         │
│    - 随着对话增长会溢出与遗忘                                │
│    - 定期使用 /compact 指令提纯                               │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ 学员实操任务清单

### Task 1: 使用原生 `/init` 指令生成基础护栏
1. 打开 Claude Code CLI 窗口，输入原生初始化指令：
   ```text
   /init
   ```
2. AI 将自动扫描当前项目目录，并在根目录下生成基础的 `CLAUDE.md` 文件。

---

### Task 2: 补充 4 大防错红线并盖章落盘
1. 检查生成的 `CLAUDE.md`，要求 AI 补充以下 4 大物理防错红线：
   - 规则 1：**包管理器硬约束**：强制统一使用 `npm`，绝对禁止混用 `yarn` 或 `pnpm`。
   - 规则 2：**边界控制**：禁止修改未在 `allowed_files` 许可范围内的任何文件。
   - 规则 3：**代码规范**：优先使用 Early Return（早期返回），消除深层嵌套。
   - 规则 4：**异常捕获**：强制进行边界条件检查与 Error Handling。
2. 在聊天窗口下发盖章落盘口令：
   ```text
   同意保存 CLAUDE.md 项目护栏配置
   ```
3. 打开工程根目录下的 [`CLAUDE.md`](file:///d:/AILearning/CLAUDE.md)，确认 4 大红线已成功落盘。

---

### Task 3: 上下文提纯与 S/L 存读档演练
1. **测试 Harness 防护效果**：向 AI 提问：
   ```text
   我们可以用 yarn 安装一个新包吗？
   ```
   *预期回答*：AI 引用 `CLAUDE.md` 规则拒绝，并提示“根据项目 Harness 规定，禁止使用 yarn，必须统一使用 npm”。
2. **上下文提纯 (Compact)**：在 CLI 中输入：
   ```text
   /compact
   ```
   清理短期对话缓存，提纯核心上下文。
3. **S/L 存读档还原 (State Restore)**：关闭 CLI 窗口并重新打开，下发自然口令：
   ```text
   请读取 IMPLEMENTATION_PLAN 恢复当前 Step 状态
   ```
   *预期效果*：AI 在 1 秒内读取磁盘中期记忆，精准汇报“已恢复进度：当前处于 Step 2 READY 状态”。

## ❓ 常见问题与纠偏 (Misconceptions)

| 误区 | 正确理解 | 纠偏动作 |
| :--- | :--- | :--- |
| 把所有规则写在对话框里 | 对话框是短期记忆，对话变长后 AI 必然产生幻觉与遗忘。 | 将长期规则统一写入 `CLAUDE.md` 磁盘文件。 |
| 手动从头撰写 `CLAUDE.md` | 原生 `/init` 命令可一键自动扫描生成初稿，只需补充业务红线。 | 使用 `/init` 快速初始化，减少手动配置工作量。 |

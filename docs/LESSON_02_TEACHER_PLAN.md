## 2. 本课定位

说明：
- **解决什么学习问题**：帮助学员破除“美化页面就是抄颜色”或“美化页面会把业务改坏”的误区，掌握结合脱敏参考图布局、`DESIGN.md` 设计规则与 Keep/Omit/Remove/Modify 裁决矩阵，将第一课的粗糙雏形重构为企业级高颜页面的方法。
- **为什么安排在当前阶段**：第 1 课解决了“从无到有”，本课解决“从粗糙到规范好看”，为后续需求深化与组件拆解奠定高保真视觉基底。
- **与前后课的关系**：衔接第 1 课生成的雏形；第 3 课在此高颜页面基础上，使用 `grill-me` 深入澄清业务功能卡。

---

## 3. 核心目标

1. 掌握从参考图中提取布局结构与主次焦点、禁用参考图杂色的方法。
2. 理解 `DESIGN.md` 设计规范的约束优先级（`业务需求 > DESIGN.md > 现有组件 > 参考图`），能将样式正确映射为项目 `--art-*` Tokens。
3. 掌握 Keep / Omit from Reference / Remove from Current Page / Modify 裁决矩阵，能建立明确的业务逻辑冻结线。
4. 掌握主管 Git 3 步可视化安全防护法（改前 Commit 存档、Diff 红绿监视 AI 越界、一键 Discard 还原）。
5. 完成一个页面、3 项最小视觉改进（首屏视觉层级、布局间距、状态/动作显眼度），并获得验证脚本 `[PASS]`。

---

## 4. 可见成果

学员完成对自己第一课页面的视觉重构：
1. 一个经过标准化美化、符合企业级设计规范的高颜业务页面；
2. 样式 100% 映射至 `--art-*` 设计 Token，无硬编码杂色；
3. 第一课确认的业务逻辑与模拟数据保持 100% 完整；
4. 运行 `verify-student-project.ps1` 校验成功获得 `[PASS]`，成果截图保存至 `local-backups/lesson-02-evidence/`。

## 10. 教师演示步骤 (5 个暂停点)

> 💡 **演示前口播**：“今天讲师使用监控与决策型案例演示重构过程，三类原型的视觉提取与 Keep/Omit/Modify 裁决逻辑完全通用。”

### 暂停点 1：参考图结构提取 (Task 1 阶段)
* **教师动作**：展示参考图卡 `ref-monitor-decision.png`，指示 Claude 提取首屏布局，强调禁用参考图杂色。
* **教师提问**：“参考图上的所有元素和颜色我们都要抄过来吗？”
* **结论**：不抄杂色与无关修饰，只借用首屏布局与视觉主次。

### 暂停点 2：DESIGN.md 变量映射 (Task 2 阶段)
* **教师动作**：读取 `DESIGN.md`，展示样式显式映射到 `--art-primary`、`--art-card-bg` 等 Token。
* **教师提问**：“AI 为什么不能直接用参考图里的背景色？”
* **结论**：设计系统规范优先！必须统一使用项目已有的 `--art-*` 变量，确保全局品牌一致性。

### 暂停点 3：下达 Keep/Modify 裁决 (Task 3 阶段)
* **教师动作**：展示 Keep/Omit/Remove/Modify 裁决矩阵，在 Keep 中填入第一课已确认的订单超时计算公式。
* **教师提问**：“为什么视觉重构时要特别标明 Keep？”
* **结论**：划定业务逻辑冻结线，防止 AI 在改样式时顺手改乱了业务字段或计算公式。

### 暂停点 4：Agent 连续重构 (Task 3 执行阶段)
* **教师动作**：发送“同意方案，请开始修改代码”，展示 Agent 自动重构样式并运行自测。
* **教师提问**：“Agent 在改样式时改变业务计算公式了吗？”
* **结论**：没有，Agent 严格在主管下达的已授权范围内连续工作。

### 暂停点 5：试衣镜对比与验收 (Task 4 阶段)
* **教师动作**：打开试衣镜展示美化后的高颜效果，运行 `verify-student-project.ps1` 输出 `[PASS]`。
* **教师提问**：“美化完成后如何验证工程没有改崩？”
* **结论**：通过本地试衣镜观察视觉效果，并配合 `verify-student-project.ps1` 脚本自动化验证。

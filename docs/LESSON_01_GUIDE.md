# 第一课：从业务问题创建第一个系统页面

## 1. 课程目标

第一课不是学习Vue语法，也不是从空目录搭建技术工程。

学员需要完成：

1. 描述一个真实、具体的业务问题
2. 确定系统名称和主要使用者
3. 确定首页最重要的信息
4. 让Claude Code创建一个可运行页面
5. 完成一次页面检查和代码验证

## 2. 已准备好的能力

项目已经具备：

- 前端工程
- 企业系统布局
- 统一设计规范
- KPI卡片
- 筛选面板
- 状态标签
- 通用表格
- 月份选择器
- 折线图
- 柱状图
- 饼图
- 组件展示页面

第一课不需要安装新框架。

## 3. 打开项目

进入项目：

```powershell
cd D:\AILearning
```

启动项目：

```powershell
npm run dev
```

启动Claude Code后，先要求它阅读：

```text
CLAUDE.md
README.md
DESIGN.md
docs/COMPONENT_CATALOG.md
docs/LESSON_01_GUIDE.md
```

## 4. 描述业务问题

先回答：

1. 系统叫什么？
2. 谁会使用？
3. 他们现在遇到什么具体问题？
4. 首页最先需要看到什么？
5. 使用者进入首页后首先执行什么操作？

不要只说：

“帮我做一个高级智能管理平台。”

应当说明真实工作场景。

## 5. 第一课需求模板

可以向Claude Code输入：

```text
我要创建一个【系统名称】。

主要使用者是【角色】。

他们现在的问题是【具体业务问题】。

首页最重要的是看到【信息、异常、任务或结果】。

使用者进入首页后首先要执行【操作】。

第一版只使用模拟数据，不接真实接口。

请先读取项目中的：
- CLAUDE.md
- DESIGN.md
- docs/COMPONENT_CATALOG.md

先向我说明：
1. 你对需求的理解
2. 第一版页面区块
3. 准备复用的现有组件
4. 准备修改的文件
5. 本次明确不做的内容

在我确认前不要修改文件。
```

## 6. 确认第一版范围

Claude Code的方案应当包含：

- 明确的页面标题
- 必要的筛选或操作
- 三到四个关键指标
- 一个主要图表或信息区
- 一个小型明细表格
- 至少一个可以点击的操作

第一版不要一次加入所有设想。

## 7. 推荐复用组件

根据需求选择：

- 指标：`KpiCard`
- 筛选：`FilterPanel`
- 状态：`StatusTag`
- 表格：`DataTable`
- 月份：`MonthRangePicker`
- 趋势：`SimpleLineChart`
- 对比：`SimpleBarChart`
- 构成：`SimplePieChart`
- 无数据：`ArtEmptyState`

不要为单个页面重复创建功能相同的组件。

## 8. 页面检查

完成页面后检查：

- 页面名称是否清楚
- 主要使用者是否明确
- 信息顺序是否合理
- 关键结论是否容易找到
- 是否有下一步操作
- 是否只使用模拟数据
- 是否没有真实接口
- 是否遵循 `DESIGN.md`
- 是否优先复用了现有组件

## 9. 代码验证

执行：

```powershell
npm run typecheck
npm run build
```

两项通过后，再运行：

```powershell
npm run dev
```

检查实际页面。

## 10. 第一课完成标准

第一课完成以下内容即可：

- 一个新的业务页面
- 一个侧边栏入口
- 清楚的页面标题
- 模拟数据
- 至少一个可操作交互
- 类型检查通过
- 构建通过

第一课不做：

- 登录
- 权限
- 数据库
- 真实接口
- MCP
- 多Agent
- 自动写入
- 生产部署

## 2. 本课定位

- **本课解决什么学习问题**：帮助业务主管破除对技术开发的恐惧，建立“用自然语言控盘 Agent 从零创造业务系统页面”的控制感。
- **为什么安排在当前阶段**：作为首门课程，重点是激发兴趣与确立业务主导权，而非教授编程语法或复杂工程结构。
- **与前一课和后一课的关系**：本课产出第一个可运行的系统页面；下一课（第 2 课）将引入参考图与设计规则（`frontend-design`）提升页面质感。

---

## 3. 核心目标

1. 能够用自然语言清晰描述一个真实具体的业务场景与核心痛点（明确系统名、角色、痛点、首要信息与首个动作）。
2. 掌握“需求表达 -> 方案裁决 -> 代码生成 -> 3轮自然语言微调”的人机协作闭环。
3. 独立完成一次基础工程自测（`verify-student-project.ps1`），产生第一个可预览、可点击交互的模拟数据页面。

---

## 4. 可见成果

* 侧边栏新增一个专属业务菜单入口。
* 一个包含页面标题、关键指标、核心信息/图表和明细表格的全新页面。
* 经过至少 3 次学员主动微调修正的真实业务逻辑呈现。
* 一份完整记载业务思考与下一步规划的课后记录。

---

## 5. 本课明确不做

- 不讲解 Vue/React、TypeScript 代码语法。
- 不安装任何第三方框架或数据库。
- 不开发登录、权限、真实 API 接入。
- 不引入 MCP 或多 Agent 分工。

**超时救急预案**：若开课 15 分钟后仍有学员未完成环境准备，**立即提供教师预装备用环境或通过远程备用机操作**，严禁压缩 Task 1 和 Task 2 的业务思考时间。

## 9. 教师 5-8 分钟微型演示教案 (Micro-Demo)

### 场景背景
* **业务问题**：客服主管每天不知道哪些高价值订单即将超时。
* **目标**：示范完整的“输入需求 -> 裁决方案 -> 生成页面 -> 一次微调”闭环。

### 演示步骤
1. **输入示范 Prompt**：
   ```text
   我要创建一个【订单履约超时预警台】。主要使用者是【客服主管】。
   主要问题是【无法及时发现即将在 2 小时内超时的订单】。
   首页最重要的是看到【超时预警列表与告警订单数】。
   请先读取 CLAUDE.md 与 docs/COMPONENT_CATALOG.md，向我说明页面结构，先不要修改代码。
   ```
2. **展示方案裁决**：当 Claude 输出页面设计后，教师示范删除一个无关的“历史统计图”，保留“告警 KPI 卡 + 超时明细表”。
3. **指令生成与预览**：输入“同意该方案，请开始修改代码”。生成完成后刷新浏览器展示页面。
4. **演示一次微调**：输入“把明细表里的跟进按钮改成红色的【立即催发货】”，展示页面实时生效。
5. **结束演示**：告知学员：“这就是自然语言人机协作的全过程，现在请大家用各自真实的业务问题开始操作。”

## 10. 学员实操任务指引 (Student Tasks)

具体学员提示词模板与操作步聚，详见 [LESSON_01_GUIDE.md](file:///d:/AILearning/docs/LESSON_01_GUIDE.md)。教师控场重点如下：

* **Task 1 控场点**：防止学员输入空泛的“帮我做个智能平台”，强制要求填写 5 项具体业务要素。检查 Claude 是否复述了需求且**没有直接改文件**。
* **Task 2 控场点**：提醒学员第一版要克制，保留 1 个页面、1 个核心信息区、1 个操作入口即可。
* **Task 3 控场点**：生成代码后，确保学员在浏览器中看到真实侧边栏入口与页面。
* **Task 4 控场点**：督促学员完成 3 轮微调（如修改业务术语、调整排列顺序、增加预警标签），体验主动掌控感。

## 11. 常见卡点救援策略 (Troubleshooting)

| 常见卡点 | 现象 | 教师救援动作 / 救急提示词 |
| --- | --- | --- |
| **Claude 未按要求先给计划，直接改了代码** | 终端直接开始做修改 | 输入：`请立即停止修改。恢复刚才的文件，按照要求先回答我对需求的理解和页面区块规划。` |
| **贪大求全，第一版生成失败或报错** | 提出了几十个页面和复杂逻辑 | 输入：`请大幅简化方案。第一版只保留 1 个核心 KPI、1 个主要明细表和 1 个模拟数据按钮。` |
| **页面样式错乱或不符合设计规范** | 颜色浮夸或文字挤压 | 输入：`请严格阅读并遵循项目中的 DESIGN.md 规范，重新调整页面的边距、配色与组件样式。` |
| **验证脚本失败** | `verify-student-project.ps1` 报错 | 检查是否漏掉了侧边栏路由配置，输入：`请运行 typecheck 检查类型错误，并补全 router/index.ts 中的侧栏路由。` |

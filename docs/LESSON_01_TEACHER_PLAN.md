## 2. 本课定位

说明：
- **解决什么学习问题**：帮助业务主管破除对 AI 开发的恐惧，掌握“用自然语言控盘 Agent 从零创造业务页面”的控制感，并理解 **LLM、Tools、Agent、ReAct 和 Workflow** 5 个核心概念。
- **为什么安排在当前阶段**：作为首门课程，重点是激发兴趣、确立业务主导权并建立人机协作规范。
- **与前后课的关系**：本课建立概念认知与可运行页面；第 2 课引入设计规则（`frontend-design`）提升质感；第 9 课深入业务 Agent 场景判断与产品设计。

---

## 3. 核心目标

1. 理解并用自己的话说明 **LLM、Tools、Agent、ReAct 和 Workflow** 5 个基础概念。
2. 能在 Claude Code 页面制作过程中准确识别这五个概念对应的实际动作。
3. 掌握“需求表达 -> 方案裁决 -> 代码生成 -> ReAct 微调”的人机协作闭环，能使用 Workflow 确认门禁有效控制 Agent。
4. 完成至少 1 次高质量人在回路的 ReAct 微调闭环（含运行 `verify-student-project.ps1` 校验通过），产生第一个可交互的模拟数据页面。

---

## 4. 可见成果

* 一个包含 LLM、Tools、Agent、ReAct、Workflow 的清晰人机协作认知。
* 侧边栏新增一个专属业务菜单入口。
* 至少一个核心业务信息区（如 KPI 卡片、任务列表或数据表格组合）。
* 经过至少 1 次人在回路高质量微调修正的真实业务逻辑呈现。
* 一份填写完整的课后概念与业务复盘记录。

---

## 5. 本课明确不做

- 不讲解 Transformer、Token 计算、Vector/Embedding 或 Function Calling 协议。
- 不讲解 LangGraph、API Schema 或 Agent 框架源码。
- 不开发登录、权限、真实 API 接入。
- 不把 Agent 描述为完全自主、可脱离人工管理的系统。

| 时段 | 时长 | 环节 | 教学目标与动作 |

| 0–8 分钟 | 8 分钟 | 成果展示 | 打开本地 `http://127.0.0.1:8888` 展示目标原型效果，展示 `lesson-flow.png` 全景关系图 |
| 8–25 分钟 | 17 分钟 | 连续微型演示 | 讲师示范“订单履约超时预警台”，进行 5 次暂停提问，揭示 LLM、Tools、Agent、ReAct、Workflow |
| 25–35 分钟 | 10 分钟 | 概念核对 | 学员对照演示回答 5 个概念分别对应刚才的哪个实际动作 |
| 35–50 分钟 | 15 分钟 | Task 1：LLM 阶段 | 学员填写 5 项业务输入，体验“本步骤不主动调用新的文件读写 Tools，仅观察 LLM 生成方案” |
| 50–60 分钟 | 10 分钟 | Task 2：Tools 与眼睛 | 引导 Claude 使用 Tools 读取 `CLAUDE.md` 与组件库，修订方案 |
| 60–75 分钟 | 15 分钟 | Task 3：Workflow & 人在回路 | 主管确认门禁，授权 Agent 连续完成页面、路由与侧栏修改 |
| 75–85 分钟 | 10 分钟 | Task 4：ReAct 微调闭环 | 观察试衣镜，发起 1 次人在回路高质量微调闭环与脚本验证 |
| 85–90 分钟 | 5 分钟 | 总结复盘 | 填写第一课记忆卡，用自己的页面复述五个概念 |

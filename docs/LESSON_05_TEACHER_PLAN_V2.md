## 1. 课程元数据
- **课程名称**：AI 业务原型开发训练营·第五课
- **主讲主题**：建立不会轻易失控的项目：工程 Harness 护栏与三分记忆机制

## 2. 本课定位
- **在全套课程中的位置**：承接第四课《受控 Agent 循环与物理状态机》，为工程构建建立持久化防护墙与记忆治理机制。
- **解决的核心痛点**：对话超过 30 轮后，AI 产生“幻觉”与“规则遗忘”，擅自混用包管理器或修改越界核心代码。
- **核心突破口**：引入“工程 Harness 鞍具 (`CLAUDE.md`)”与“三分记忆模型”，物理锁死 Agent 的行为红线，并支持 S/L 存读档一秒恢复会话断点。

## 3. 核心目标与 Bloom ABCD 能力矩阵

### 3.1 核心大观与本质提问 (Backward Design Stage 1)
- **核心大观 (Big Idea)**：不要信任 AI 的短期口头承诺，必须用物理磁盘上的 `CLAUDE.md` 护栏与三分记忆模型，锁定 Agent 的所有行为红线。
- **本质提问 (Essential Question)**：当跨会话开发或 AI 对话过长产生注意力衰减时，如何保证团队红线永不遗忘，且能 1 秒无缝恢复开发进度？

### 3.2 Bloom ABCD 学习目标
完成本课后，学员将能够：
1. **[Objective 1 - Apply (3)]**：在给定的项目工程目录下 (**C**)，学员 (**A**) 能运行原生 `/init` 命令行指令 (**B**)，秒级生成并配置包含 4 大防错红线的 `CLAUDE.md` 项目护栏 (**D**)。
2. **[Objective 2 - Analyze (4)]**：在面对对话增长引发的 Context 膨胀时 (**C**)，学员 (**A**) 能通过 `/compact` 提纯指令与物理挂载机制 (**B**)，彻底消除 AI 的包管理器误用与规则遗忘 (**D**)。
3. **[Objective 3 - Evaluate (5)]**：在跨会话或断电重开场景下 (**C**)，学员 (**A**) 能下发自然恢复指令 (**B**)，实现 1 秒内无缝读取磁盘状态机并恢复开发断点 (**D**)。

## 11. 核心概念四步解析卡集

### 💡 概念卡 1：Engineering Harness (工程鞍具 / 物理护栏)
1. **硬核工程定义**：约束 Agent 行为边界的物理配置文件、校验脚本与权限防火墙组合。
2. **底层运作机制**：在 Agent 修改代码前强制读取 Harness 规则，违规指令直接拦截。
3. **具象业务比喻**：**赛马的鞍具与缰绳** 🏇。
4. **IT 沟通场景**：“我们为项目部署了工程 Harness 护栏，物理锁定了包管理器与编码规则。”

### 💡 概念卡 2：三分记忆模型 (3-Layer Memory Architecture)
1. **硬核工程定义**：将 Agent 记忆划分为“长期 (`CLAUDE.md`)”、“中期 (`IMPLEMENTATION_PLAN.md`)”与“短期 (Context Buffer)”的三层解耦架构。
2. **底层运作机制**：长期规则物理挂载 Prompt 顶部，中期进度落盘防丢，短期缓存使用 `/compact` 提纯。
3. **具象业务比喻**：**公司章程 + 盘点账本 + 电话记事本** 📝。
4. **IT 沟通场景**：“项目建立了三分记忆模型，有效防止了 AI 规则遗忘。”

### 💡 概念卡 3：S/L 存读档状态恢复机制 (State Save / Load Restore)
1. **硬核工程定义**：通过读取磁盘持久化状态机文件无缝重建 LLM 注意力锚点并恢复断点任务的机制。
2. **底层运作机制**：重开终端后读取 `current_waiting_step` 恢复上下文。
3. **具象业务比喻**：**单机游戏的 S/L 存档与读档** 🎮。
4. **IT 沟通场景**：“我们支持 S/L 存读档状态恢复，跨会话开发时 1 秒无缝接续进度。”

## 12. 5 个固定 Pause Points 控场问答指南
- **Pause Point 1 (08分)**：问：“为什么不能把规则只写在聊天框里？” ➔ 答：“聊天框是短期记忆，对话增多会引发 Token 溢出与规则遗忘。”
- **Pause Point 2 (18分)**：问：“`CLAUDE.md` 护栏存放在哪里？有什么物理效果？” ➔ 答：“存放在根目录，每轮对话开端自动物理挂载到 Prompt 顶部。”
- **Pause Point 3 (25分)**：问：“`/init` 指令的物理本质是什么？” ➔ 答：“官方原生指令，自动一键扫描工程结构并生成 Harness 框架。”
- **Pause Point 4 (35分)**：问：“`/compact` 指令有什么用？” ➔ 答：“压缩清理过期的短期对话 Token，保留核心上下文。”
- **Pause Point 5 (80分)**：问：“断电重开后如何恢复进度？” ➔ 答：“读取磁盘 `IMPLEMENTATION_PLAN.md` 物理状态机，1 秒无缝 S/L 读档恢复。”

🎯 三层能力成熟度演进模型

  • 第一层：Prompting (单次指令) —— 通过单次指令描述任务，理解裸 Prompt 容易引发脑补的物理局限。
  • 第二层：Harness Engineering (工程护栏) —— 通过规则 (`CLAUDE.md`)、文件 (`PROJECT_STATE.md`)、Skills (`grill-me`, `design-lint`) 与测试脚本强行约束 Agent。
  • 第三层：Bounded Agent Loop (受控 Agent 循环) —— 在明确目标、边界、工具与停止条件下，让 Agent 进行受控自主循环，主管在关键关口行使人在回路 (HITL) 盖章。

🛡️ 高阶工程防错 5 大防护规则

  1. Subagent 超时熔断规则：静默后台任务设置物理超时（如 60s），超时自动释放，绝不挂起主 Agent。
  2. Subagent 预授权只读沙箱：静默后台 Subagent 仅继承只读工具，所有代码写盘修改必须由主管签署 HITL 口令。
  3. 产物强制物理落盘规则：测试截图与 DOM 操作日志必须物理落盘写盘，决不随 Context 重置而蒸发。
  4. 双 Agent 两轮仲裁门禁：开发 Agent 与审查 Agent 辩论超 2 轮强制阻断，由主管 CEO 进行终审盖章。
  5. Mock 数据降级保护桥梁：真 API 连接失败或超时时，自动降级回 Mock Data，保证原型 100% 不白屏崩溃。

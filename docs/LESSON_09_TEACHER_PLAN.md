## 一、 课程元数据与定位

### 1.1 课程元数据
- **课程名称**：AI 业务原型开发训练营·第九课
- **主讲主题**：业务 Agent 场景判断与产品设计：确定性逻辑切割与 Mock 降级保护桥梁
- **授课对象**：非技术背景业务主管 / 产品经理 / 业务专家 (10–30人)
- **课时时长**：90 分钟 (极客控场 + 5 个固定 Pause Points)
- **授课模式**：18 分钟极客示范 ➔ 10 分钟概念核对 ➔ 45 分钟学员分步实操 ➔ 10 分钟验证归档
- **前置依赖**：学员已完成第八课并掌握 Codex 独立审查、上下文隔离与 AUDIT_REPORT 终局裁决。
- **教学验证状态**：PILOT_READY (包含确定性逻辑切割、API MCP 插座挂载与 Mock 降级保护演示 / 待试讲)
- **课程负责人**：训练营教研组

### 1.2 本课定位与背景痛点
- **在全套课程中的位置**：“五、受控 AI 闭环与 IT 交接”阶段的开篇课，解决前端原型如何连接数据接口、如何划分 AI 与经典代码边界、以及如何防止接口宕机导致演练崩盘的硬核问题。
- **解决的核心痛点**：
  1. **逻辑混淆**：滥用 LLM 处理本该由确定性代码（计算、扣费、状态流转）完成的规则，导致业务算错账。
  2. **网络依赖与演示白屏死穴**：向老板或 IT 汇报演练时，真实 API 接口超时或断网，导致前端页面整个白屏打回。
- **核心突破口**：
  1. **确定性 vs. 概率性逻辑切割**：计算与状态扣减由 TypeScript 确定性代码执行，智能生成由 LLM 执行并经过 HITL 确认。
  2. **API MCP 插座 (API MCP Socket)**：为 Agent 挂载标准化接口插座，输出符合 TypeScript 契约的结构化 JSON。
  3. **Mock 降级保护桥梁 (Mock Fallback Bridge)**：真实 API 故障时，0.1 秒内无缝降级加载本地静态底稿，确保汇报演练 **0 白屏、100% 稳定**！

## 二、 逆向目标与四步概念卡

### 2.1 Bloom ABCD 学习目标
完成本课后，学员将能够：
1. **[Objective 1 - Apply (3)]**：在给定的业务原型工程中 (**C**)，学员 (**A**) 能应用确定性与概率性逻辑切割范式 (**B**)，将价格计算与状态扣减剥离给 TypeScript 确定性代码执行 (**D**)。
2. **[Objective 2 - Analyze (4)]**：在连接外部 API 接口时 (**C**)，学员 (**A**) 能分析 API MCP 插座的结构化 JSON 契约 (**B**)，并挂载 API MCP Server (**D**)。
3. **[Objective 3 - Evaluate (5)]**：在模拟网络断网或 API 超时场景下 (**C**)，学员 (**A**) 能评估 Mock 降级保护桥梁的熔断表现 (**B**)，验证 0.1 秒内无缝降级至本地静态底稿以确保 100% 演示不白屏 (**D**)。

### 2.2 核心概念四步解析卡集

#### 💡 概念卡 1：Deterministic vs Probabilistic Logic Split (确定性规则与概率性生成逻辑切割)
1. **硬核工程定义**：在系统设计中，将“数值计算、状态流转、权限判定”划归为结果 100% 确定、零随机度的经典代码逻辑（确定性）；将“文本生成、语义推演、智能总结”划归为 LLM 大模型逻辑（概率性）的架构隔离范式。
2. **底层运作机制**：算术与条件分支由 TypeScript 函数直接执行；LLM 仅负责填空、生成与提取，且 LLM 输出结果必须经过 Schema 校验与 HITL 主管确认。
3. **具象业务比喻**：**收银机计算器与前台推销员的分工** 🧮👨‍💼。算钱扣款用收银机（确定性），推销问候用推销员（概率性），推销员绝不能擅自算账扣钱。
4. **IT 沟通场景**：“我们在架构上对确定性算式与概率性 AI 推演进行了物理切割，核心逻辑 100% 由 TypeScript 代码硬核保障。”

#### 💡 概念卡 2：API MCP Server & Tooling Socket (API MCP 接口插座与协议)
1. **硬核工程定义**：符合 Model Context Protocol 规范的 API 连接插座，为 Agent 提供标准化获取外部数据、调用后端 Mock 接口与输出 TypeScript 结构化 JSON 的扩展接口。
2. **底层运作机制**：Agent 通过 JSON-RPC 下发 API 请求 Tool Call，API MCP Server 代理请求后端服务并将数据按契约 Schema 解包返回。
3. **具象业务比喻**：**墙上的标准三孔电源插头与插座** 🔌。无论是接入 Mock 数据源还是真实 API 数据库，只需插上 MCP 插座，Agent 即可即插即用获取数据。
4. **IT 沟通场景**：“我们的 AI 原型通过标准 API MCP 插座连接了后端 Mock 接口，实现了前端 UI 与后端数据契约的无缝对接。”

#### 💡 概念卡 3：Mock Fallback Bridge (Mock 降级保护桥梁)
1. **硬核工程定义**：在外部 API 接口出现超时、断网、4xx/5xx 报错或格式异常时，系统自动捕抓异常并在 0.1 秒内回退加载第 3 课 `src/mocks/prototype-data.ts` 本地静态数据的容错机制。
2. **底层运作机制**：在数据请求层外包裹 `try-catch-fallback` 保护桥梁。只要 API 抛错或响应超过 2000ms，熔断器自动触发并无缝加载本地底稿数据，Console 抛出降级警告。
3. **具象业务比喻**：**大厦的双路供电与备用发电机** ⚡。主电网（外部 API）一旦停电，备用发电机（Mock 数据）0.1 秒自动启动，大楼灯火通明、演练绝不出错。
4. **IT 沟通场景**：“原型部署了 Mock 降级保护桥梁，即便外部 API 崩溃，演示依然能依靠本地底稿 100% 稳定运行。”

## 五、 逐 Task 极客示范与巡视指导

### Task 1: 确定性与概率性逻辑切割实操
- **教师示范**：在代码中将价格计算逻辑剥离给 TypeScript 确定性函数 `calculateTotal()`，LLM 仅生成文本推荐语。
- **盖章口令**：`执行逻辑切割：算术与扣减归 TypeScript 代码，摘要推荐归 LLM`
- **巡视 Check**：确认算术逻辑不再由 LLM 生成，结果 100% 确定。

### Task 2: 挂载 API MCP 插座连接后端 Mock 数据接口
- **教师示范**：为 Agent 挂载 API MCP Server，请求后返回结构化 JSON。
- **盖章口令**：`唤醒 API MCP 插座，连接后端 Mock 结构化数据`
- **巡视 Check**：API 返回的数据精准匹配 `prototype-data.ts` 的 TypeScript 契约。

### Task 3: 触发 Mock Fallback Bridge (模拟断网/超时降级保护)
- **教师示范**：模拟 API 请求 2000ms 超时或断网，演示 0.1 秒内页面无感无缝降级渲染本地 `prototype-data.ts`。
- **盖章口令**：`模拟 API 故障，触发 Mock 降级保护桥梁测试`
- **巡视 Check**：确认网络中断后页面无白屏崩盘，控制台打印出降级 Warning 日志。

### 6.1 常见错误现场 Troubleshooting
- **现象 1**：API 超时后页面出现空白 ➔ **预案**：检查 `try-catch` 块中是否未正确返回 `prototypeData` 缺省对象。

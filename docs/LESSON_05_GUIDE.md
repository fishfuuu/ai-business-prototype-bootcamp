# 第五课学员操作指南 — 建立不会轻易失控的项目：单 Agent 控制流、工程 Harness 护栏与记忆机制

> 💡 **本课的核心思想只有一句话：**  
> **理清单 Agent 控制流范式，用 `CLAUDE.md` 物理护栏与三分记忆模型锁死 Agent 的所有行为红线。**

---

## 一、 本课背景、底层原理与学习目标

### 1.1 业务背景与真实痛点
在跨会话或多人协同的 AI 开发中，最让人头疼的问题是：**不了解 AI 内部是如何思考与决策的，且 AI 经常产生“幻觉”或“遗忘”**。例如，对话进行了 30 轮后，AI 突然忘记了团队统一使用 `npm` 的规定，擅自使用了 `yarn` 或 `pnpm` 安装第三方包；或者在修改代码时擅自改动了未授权的系统核心路由，导致工程环境被搞崩。

### 1.2 宏观安全治理与记忆流转闭环
本课的核心工程机制，是将单 Agent 3 大控制流范式、项目安全红线与会话记忆治理纳入一条**“控制流理清 ➔ 物理挂载 ➔ 规范拦截 ➔ 盘存留痕 ➔ 上下文提纯 ➔ 断点恢复”**的受控闭环中：
1. **单 Agent 控制流理清 (Control Flow Analysis)**：理解 ReAct 思考-行动循环、Plan-and-Execute 规划与执行分离、Reflection 自我反思与纠偏 3 种标准控制流。
2. **物理挂载与规范拦截**：根目录下的 `CLAUDE.md` 护栏在每轮对话开端自动物理挂载至 Prompt 顶部，干预 ReAct 工具调用，拦截越界文件修改与非法包管理器指令。
3. **磁盘盘存与进度留痕**：通过 `IMPLEMENTATION_PLAN.md` 物理文件将 Step 状态与 SHA 记录持久化存在本地磁盘，脱离对聊天窗口短期记忆的依赖。
4. **上下文提纯与断点恢复**：通过 `/compact` 指令定期清理压缩过期对话 Token；在重新开机或断电后，直接读取磁盘状态机文件 1 秒无缝恢复开发断点。

### 1.3 核心学习目标
完成本课实操后，你将能够：
1. 理解单 Agent 3 大控制流范式（ReAct、Plan-and-Execute、Reflection）及其在 `CLAUDE.md` 护栏下的干预点。
2. 掌握使用原生 `/init` 命令行指令，秒级生成并配置项目专属的 `CLAUDE.md` 护栏。
3. 掌握使用 `/compact` 清理提纯短期上下文，结合 `CLAUDE.md` 彻底消除 AI 幻觉与规则遗忘。
4. 掌握断电/重新开机场景下的 S/L 存读档状态恢复机制 (`State Restore`)。

## 二、 💡 本课核心工程概念卡 (Core Concepts)

### 核心概念 1：Single-Agent Control Flow Paradigms (单 Agent 3 大控制流全景)
- **硬核工程定义**：单个 AI Agent 内部驱动任务推进的 3 种标准控制流范式，包含 ReAct (思考-行动闭环)、Plan-and-Execute (规划与执行分离) 与 Reflection / Self-Correction (自我反思与纠偏)。
- **底层运作机制**：
  - **ReAct 范式**：`Thought (思考) ➔ Action (调用工具) ➔ Observation (观察) ➔ Thought`，实时工具调用尝试。
  - **Plan-and-Execute 范式**：`Planner (拆解) ➔ Executor (执行) ➔ Replanner (重新规划)`，大功能结构化开发。
  - **Reflection 范式**：`Generate (生成) ➔ Critic (断言) ➔ Self-Correct (自动修正)`，用于 Bug 诊断与死循环熔断。
- **具象业务比喻**：**探险家 🧭、建筑师 📐 与自带质检员的学生 ✍️**。
- **IT 沟通场景**：“我们分析了 Agent 的 3 大控制流范式，并通过护栏干预了其 ReAct 工具调用与 Reflection 熔断。”

### 核心概念 2：Engineering Harness (工程鞍具 / 物理护栏)
- **硬核工程定义**：为了约束 AI Agent 行为边界而建立的物理配置文件 (`CLAUDE.md`)、自动化校验脚本与权限防火墙组合。
- **底层运作机制**：在 Agent 发起系统调用或修改代码前，强制读取 Harness 规则，违规指令直接被防火墙拦截。
- **具象业务比喻**：**赛马的鞍具与缰绳** 🏇。给野马戴上鞍具和缰绳，骑手（主管）才能精准把控方向，确保 AI 奔跑时不脱轨。
- **IT 沟通场景**：“我们为项目部署了工程 Harness 护栏，物理锁定了包管理器与编码规则，确保 AI 生成的代码安全可控。”

### 核心概念 3：3-Layer Memory Architecture (三分记忆模型)
- **硬核工程定义**：将 AI Agent 的记忆划分为“长期物理记忆 (`CLAUDE.md`)”、“中期进度记忆 (`IMPLEMENTATION_PLAN.md`)”与“短期对话缓存 (Context Buffer)”的三层解耦架构。
- **底层运作机制**：长期规则在每轮对话开始时物理挂载在 Prompt 顶部；中期进度通过磁盘文件防丢；短期缓存随对话增长定期使用 `/compact` 提纯。
- **具象业务比喻**：**公司章程(长期) + 盘点账本(中期) + 电话临时记事本(短期)** 📝。
- **IT 沟通场景**：“项目建立了三分记忆模型，有效防止了 AI 随着对话轮数增多而产生 Token 溢出与规则遗忘。”

### 核心概念 4：State Save / Load Restore (S/L 存读档状态恢复机制)
- **硬核工程定义**：通过读取磁盘上持久化的状态机文件，无缝重建 LLM 上下文注意力锚点并恢复断点任务的机制。
- **底层运作机制**：在中断对话或重新开机后重新唤醒 Agent，下发恢复指令，Agent 会直接从磁盘读取 `current_waiting_step` 恢复上下文。
- **具象业务比喻**：**单机游戏的 S/L 存档与读档** 🎮。随时保存当前通关进度，关机重开后 1 秒载入最新关卡。
- **IT 沟通场景**：“我们支持 S/L 存读档状态恢复，跨会话开发时 1 秒无缝接续上一次的实施进度。”

## 三、 🧠 单 Agent 3 大控制流与护栏干预对照表

| 控制流范式 | 核心驱动循环 | 最适用业务场景 | `CLAUDE.md` 护栏干预点 |
| :--- | :--- | :--- | :--- |
| **1. ReAct 范式** | Thought ➔ Action ➔ Observation | 基础对话、小步代码调试 | 约束 Action 工具调用边界与白名单 (禁止非授权指令) |
| **2. Plan-and-Execute 范式** | Planner ➔ Executor ➔ Replanner | 复杂增量需求拆解、大功能开发 | 强制要求生成 Checkpoint 列表，未经批准禁止跳步骤 |
| **3. Reflection 范式** | Generate ➔ Critic ➔ Self-Correct | Bug 诊断、单元测试、死循环熔断 | 强制最多 2 轮硬熔断、禁止掩盖报错与吞异常 |

## 五、 🛠️ 课堂实操与自学导引任务清单

### Task 1: 使用原生 `/init` 指令生成基础护栏

#### ⚡ 极速操作步骤
1. 打开 Claude Code CLI 窗口，输入原生初始化指令：
   ```text
   /init
   ```
2. AI 将自动扫描当前项目目录，并在根目录下生成基础的 `CLAUDE.md` 文件。

---

### Task 2: 补充 4 大防错红线并盖章落盘

#### ⚡ 极速操作步骤
1. 检查生成的 `CLAUDE.md`，要求 AI 补充以下 4 大物理防错红线：
   - 规则 1：**包管理器硬约束**：强制统一使用 `npm`，绝对禁止混用 `yarn` 或 `pnpm`。
   - 规则 2：**边界控制**：禁止修改未在 `allowed_files` 许可范围内的任何文件。
   - 规则 3：**代码规范**：优先使用 Early Return（早期返回），消除深层嵌套。
   - 规则 4：**异常捕获**：强制进行边界条件检查与 Error Handling。
2. 在聊天窗口下发盖章落盘口令：
   ```text
   同意保存 CLAUDE.md 项目护栏配置
   ```
3. 打开工程根目录下的 [`CLAUDE.md`](file:///d:/AILearning/CLAUDE.md)，确认 4 大红线已成功落盘。

---

### Task 3: 上下文提纯 (`/compact`) 与 S/L 存读档演练

#### ⚡ 极速操作步骤
1. 在 CLI 窗口中下发上下文提纯指令：
   ```text
   /compact
   ```
2. 关闭 CLI 终端窗口，重新打开终端，下发恢复断点指令：
   ```text
   请读取 IMPLEMENTATION_PLAN 恢复当前 Step 状态
   ```
3. 确认 Agent 能在 1 秒内无缝读取磁盘状态机并接续开发。

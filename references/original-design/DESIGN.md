## 2. 产品定位与设计原则

### 2.1 目标用户与核心路径

| 用户          | 关心的问题                   | 高频页面                     |
| ------------- | ---------------------------- | ---------------------------- |
| 老板 / 总经理 | 公司是否赚钱，问题在哪里     | 月度经营总览、利润看板       |
| 财务经理      | 口径准确、能对账、风险可控   | 费用总览、执行偏差、数据管理 |
| 运营主管      | 店铺和活动效果、预算达成     | 收入总览、收入达成分析       |
| 业务人员      | 我的待办、偏差解释、措施跟进 | 经营事项工作台               |

核心操作路径：**查看总览 → 发现偏差 → 定位原因 → 制定动作 → 跟踪处理**

### 2.2 设计关键词

**专业、可信、克制、清晰、数据密集但不拥挤。**

### 2.3 设计原则

1. **数据和结论优先于装饰。** 页面第一眼应传达经营结论，而非展示视觉风格。
2. **异常优先级高于普通。** 超阈值、逾期、缺口等异常状态应比正常状态更醒目。
3. **高频任务减少页面跳转。** 筛选、下钻、抽屉查看等高频操作应就近完成。
4. **不制造高级感。** 不通过增加卡片、颜色、渐变和动画制造高级感。功能正确比视觉新颖更重要。
5. **稳定复用高于局部创新。** 新增页面优先复用现有页面模式和组件，不自行设计新风格。

## 3. 视觉 Token

所有 Token 值以 `tailwind.css` 中定义的 CSS 变量为准。以下列出语义映射。

### 3.1 品牌主色

| Token   | CSS 变量                       | 用途                         |
| ------- | ------------------------------ | ---------------------------- |
| Primary | `oklch(0.7 0.23 260)` → 蓝色系 | 主操作按钮、选中态、关键链接 |

### 3.2 语义色（业务状态）

| 用途      | 亮色             | 暗色             | 业务含义                       |
| --------- | ---------------- | ---------------- | ------------------------------ |
| 正文标题  | `text-gray-900`  | `text-gray-100`  | 卡片标题、KPI 数值             |
| 辅助描述  | `text-gray-500`  | `text-gray-400`  | 标签、副标题、辅助文字         |
| 成功/节余 | `text-green-600` | `text-green-400` | 偏差额<0、费用率改善、利润上升 |
| 超支/减少 | `text-red-500`   | `text-red-400`   | 偏差额>0、费用率上升、缺口     |
| 中性/零值 | `text-gray-500`  | `text-gray-400`  | 偏差额=0，刚好达标             |
| 警告/关注 | `text-amber-500` | `text-amber-400` | 临期、需关注、小幅超支         |

### 3.3 底色与层级

| 层级     | 亮色                          | 暗色                           | 用途                 |
| -------- | ----------------------------- | ------------------------------ | -------------------- |
| 页面背景 | `bg-gray-50` / `bg-[#fafbfc]` | `bg-gray-950` / `bg-[#070707]` | 全局页面底色         |
| 卡片表面 | `bg-white`                    | `bg-gray-900` / `bg-[#161618]` | 所有内容卡片         |
| 悬浮态   | `bg-gray-50`                  | `bg-gray-800/50`               | 表格行、卡片悬浮     |
| 选中态   | `bg-blue-50`                  | `bg-blue-900/40`               | 列表选中、筛选项选中 |

### 3.4 边框

| 用途          | 亮色                                             | 暗色                          |
| ------------- | ------------------------------------------------ | ----------------------------- |
| 卡片外框      | `border-gray-100`                                | `border-gray-700/60`          |
| 表格/组件内框 | `border-gray-200`                                | `border-gray-700`             |
| 卡片阴影      | `shadow-panel`: `0 8px 24px rgba(26,37,64,0.08)` | `0 8px 24px rgba(0,0,0,0.35)` |

### 3.5 字体栈

- 正文字体：`'Fira Sans', ui-sans-serif, system-ui, sans-serif`
- 等宽字体：`'Fira Code', ui-monospace, monospace`

### 3.6 字号体系

| 用途           | Tailwind                  | px 等效 |
| -------------- | ------------------------- | ------- |
| KPI 大数值     | `text-2xl font-extrabold` | 24px    |
| 卡片/模块标题  | `text-lg font-semibold`   | 18px    |
| 正文           | `text-sm`                 | 14px    |
| 表格内容       | `text-sm`                 | 14px    |
| 描述/标签/辅助 | `text-xs`                 | 12px    |

禁止 `text-[10px]`、`text-[11px]`、`text-[15px]` 等非标准字号。

### 3.7 间距层级

| 场景       | 类              | 说明               |
| ---------- | --------------- | ------------------ |
| 卡片间距   | `gap-4`         | 网格中卡片之间     |
| 模块间距   | `mt-4` / `mb-4` | 页面中上下模块之间 |
| 卡片内边距 | `p-4` 或 `p-6`  | 内容区域与卡片边框 |
| 图表内边距 | `p-6`           | ECharts 图表容器   |

### 3.8 圆角

| 场景          | 类           | 说明                       |
| ------------- | ------------ | -------------------------- |
| 大型卡片/面板 | `rounded-xl` | 筛选栏、图表容器、KPI 卡片 |
| 表格/小卡片   | `rounded-lg` | 表格容器、状态标签         |
| 按钮/标签     | `rounded-md` | 按钮、输入框               |

### 3.9 阴影层级

| 层级      | token             | 亮色值                          | 暗色值                      |
| --------- | ----------------- | ------------------------------- | --------------------------- |
| 卡片      | `shadow-panel`    | 0 8px 24px rgba(26,37,64,0.08)  | 0 8px 24px rgba(0,0,0,0.35) |
| 悬浮      | `hover:shadow-md` | 浏览器默认                      | 浏览器默认                  |
| 弹窗/抽屉 | `shadow-dialog`   | 0 12px 32px rgba(26,37,64,0.14) | 0 12px 32px rgba(0,0,0,0.4) |

### 3.10 ECharts 统一语义色

以下配色在所有图表中保持一致，不得在不同图表中重复定义不同值：

| 状态   | 色值      | 视觉含义               |
| ------ | --------- | ---------------------- |
| good   | `#18a058` | 正常、改善、达成       |
| warn   | `#f59e0b` | 需要关注               |
| bad    | `#dc2626` | 严重异常、未达或超支   |
| nodata | `#9ca3af` | 无数据或不可判断       |

`good / warn / bad / nodata` 的业务判断条件，以 `docs/01-业务口径与指标手册.md`、`docs/03-API字段契约与状态字典.md` 或后端返回状态为准。DESIGN.md 只定义状态对应的统一视觉表达，不定义业务阈值。

## 4. 页面布局

### 4.1 通用页面结构

```
┌─────────────────────────────────────────┐
│  筛选栏（sticky top-23）                │  → 条件筛选 + 主操作按钮
├─────────────────────────────────────────┤
│  预警/口径说明（可选）                   │  → amber/red 提示条
├─────────────────────────────────────────┤
│  KPI 概览卡片（grid）                    │  → 关键数字和对比
├─────────────────────────────────────────┤
│  图表区域（grid-cols-1 lg:grid-cols-N）  │  → 趋势、结构、对比
├─────────────────────────────────────────┤
│  矩阵/明细/关注项                        │  → 健康矩阵、表格、关注列表
├─────────────────────────────────────────┤
│  AI 助手 FAB（固定右下角）               │  → 后续功能入口
└─────────────────────────────────────────┘
```

### 4.2 页面容器

- 页面根元素：`class="min-h-screen transition-all duration-300"`
- 内容容器：`class="pb-4 page-fade-in"`
- 动画入口：`page-fade-in`（内容淡入）、`scroll-reveal`（滚动渐入）、`v-reveal`（可见即入）

### 4.3 页面标题

页面顶部可设置标题和副标题，与筛选栏同级或独立：

```html
<h1 class="text-lg font-semibold text-gray-900 dark:text-gray-100">页面名称</h1>
<p class="text-xs text-gray-500 mt-1 max-w-[650px]">页面用途说明</p>
```

### 4.4 模块顺序规则

1. **筛选条件 →** 用户进入页面后先选择范围
2. **预警/口径提示 →** 当前视图的重要前提说明
3. **关键指标 →** 最核心的经营数字
4. **分析图表 →** 趋势、结构、对比
5. **明细与操作 →** 下钻后的详情、矩阵、关注项

### 4.5 多列场景

| 列数 | 适用场景 | Grid 配置 |
| --- | --- | --- |
| 3+1 | 图表占主体 + 侧边关注项 | `lg:grid-cols-4`，图表 `lg:col-span-3` |
| 5+2 | 宽图表 + 窄结构图 | `lg:grid-cols-5`，趋势图 `lg:col-span-3`，结构图 `lg:col-span-2` |
| 等宽双列 | 两个同等重要的图表 | `sm:[grid-template-columns:1fr_320px]` 或等分 |
| 列表+详情 | 左侧列表 + 右侧详情/抽屉 | `grid-cols-1 sm:grid-cols-[minmax(0,1fr)_360px]` |

### 4.6 什么时候用整页 vs 抽屉

| 场景            | 方式                                    | 说明                             |
| --------------- | --------------------------------------- | -------------------------------- |
| 主页面展示      | 整页路由                                | 总览、列表、看板                 |
| 下钻维度切换    | 整页路由（携带参数）                    | 总览 → 达成分析、总览 → 执行偏差 |
| 查看详情        | 右侧抽屉（`el-drawer direction="rtl"`） | 任务详情、偏差诊断、每日取值验证 |
| 短确认/轻量编辑 | 弹窗（`el-dialog`）                     | 确认操作、填写简短内容           |

## 5. 指标卡

### 5.1 必须内容层次

```
┌─────────────────────────────────┐
│ 指标名称    [?]                 │  ← text-sm font-semibold, 灰色
│                                 │
│  1,234.5 万                     │  ← text-2xl font-extrabold, 主色/正文色
│                                 │
│  预算    1,500.0 万             │  ← 左标签右数值
│  达成率      82.3%              │  ← flex justify-between
│  缺口     −265.5 万             │  ← 差值按业务语义着色
└─────────────────────────────────┘
```

### 5.2 着色规则

指标值的正负着色以**业务语义**判断，不以数值正负简单决定：

| 场景                | 方向       | 着色             |
| ------------------- | ---------- | ---------------- |
| 净销售额/净利润达标 | 超预算     | `text-green-600` |
| 费用超预算          | 超支       | `text-red-500`   |
| 达成率 ≥ 100%       | 超额       | `text-green-600` |
| 达成率 < 100%       | 缺口       | `text-red-500`   |
| 刚好达标            | 偏差=0     | `text-gray-500`  |
| 无预算              | 无比较基准 | `text-gray-500`  |

### 5.3 帮助图标

每个指标卡和图表标题必须带 `?` 解释图标：

```html
<el-tooltip placement="bottom" effect="dark" :content="解释文本" :show-after="300">
  <span
    class="inline-flex items-center justify-center w-4 h-4 rounded-full
    border border-gray-300 text-blue-700 bg-blue-50 text-xs font-extrabold cursor-help"
    >?</span
  >
</el-tooltip>
```

### 5.4 指标卡数量

- 总览页不超过 5 张（单行）。超过 5 个核心指标时考虑分组或减少。
- 不允许仅为填充页面布局而增加无效指标卡。

### 5.5 彩色顶条（允许模式，非必须）

指标卡顶部可加 4-6px 彩色边框（`border-t-4`）作为视觉区分，颜色序列为蓝/紫/红/黄/绿。此模式非强制，新页面可选择不使用。

### 5.6 加载与空态

- 加载中：骨架屏（`skeleton-shine` 动画），禁止显示全 0 或空白
- 无数据：显示 `--`，不显示 0
- 无预算：显示 `无预算`，禁止显示 `0%` 达成率或 `+0.0%` 偏差

## 6. 表格

### 6.1 对齐规则

| 列类型                 | 对齐     | 说明                               |
| ---------------------- | -------- | ---------------------------------- |
| 文本（科目名、平台名） | 左对齐   | `text-left`                        |
| 金额、数量             | 右对齐   | `text-right` + `tabular-nums`      |
| 比率、百分比           | 右对齐   | `text-right` + `.toFixed(1) + '%'` |
| 状态标签               | 居中对齐 | `text-center`                      |

### 6.2 单位表达

金额单位在表格上方或表头行标注。展示层级：>= 1亿 显示 `亿`（2 位小数），>= 1万 显示 `万`（1 位小数），否则千分位。

### 6.3 表格结构

```
┌──────────────────────────────────────────────┐
│  标题  [?]              单位：万元  [操作区] │  ← text-lg font-semibold + 说明
├──────────────────────────────────────────────┤
│  ┌───┬──────┬──────┬──────┬──────┬──────┐   │
│  │ 科目│ 实际 │ 预算 │ 差值 │ 费率 │ 状态 │   │  ← 表头 sticky
│  ├───┼──────┼──────┼──────┼──────┼──────┤   │
│  │ ...│      │      │      │      │      │   │  ← 行 hover 反馈
│  └───┴──────┴──────┴──────┴──────┴──────┘   │
└──────────────────────────────────────────────┘
```

### 6.4 高列数处理

1. 确定核心展示列（≤ 6 列）
2. 次要列支持横向滚动（`overflow-x-auto` + `min-width: Npx`）
3. 移动端转为核心列视图或横向滚动

注意：Element Plus `el-table` 的横向滚动不影响下拉框；如使用原生 `<table>` 配合 `overflow-x-auto`，需确认下拉菜单不被裁切（popper 用 fixed 定位）。

### 6.5 异常强调

- 异常行：不使用全行着色，仅对异常数值或状态列做标记（颜色文字或 `el-tag`）
- 周末列（PnL 表）：`!bg-amber-100/70 dark:!bg-amber-900/40`
- 当前日列：`text-blue-500 font-bold`
- 选中行：`border-blue-400 bg-blue-50 dark:bg-blue-900/40`

### 6.6 差异值表达

| 条件          | 显示       | 颜色           |
| ------------- | ---------- | -------------- |
| 有空值/无分母 | `--`       | 灰色           |
| 无预算        | `无预算`   | 灰色           |
| 0             | `0`        | 灰色（中性）   |
| 正偏差        | `+1,234.5` | 按业务语义着色 |
| 负偏差        | `−1,234.5` | 按业务语义着色 |

### 6.7 禁止事项

- 禁止给所有单元格着色表达状态（应只标记关键列）
- 禁止在金额列前加 `¥` 符号（通过单位行或列头表达）
- 禁止混用 `0` 和 `--`

## 7. 图表

### 7.1 基本原则

1. **每张图回答一个明确的业务问题。** 标题应表达分析对象（如"费用趋势总览（日趋势）"），不只写"趋势图"。
2. **同一指标跨页面保持颜色一致。** 净销售额、费用、利润等指标在不同页面使用相同系列色。
3. **状态色统一。** good/warn/bad/nodata 四色规范（见 §3.10）在所有图表中保持一致。
4. **Tooltip 必须包含完整信息。** 指标名称、时间、值、单位。禁止只显示数字。

### 7.2 图表容器

图表容器固定模式（非强制，推荐）：

```
标题（text-lg font-semibold + ? 帮助图标）
副标题（text-xs text-gray-500）
图表区域（flex-1, min-h-[350px], overflow-x-auto 可选）
骨架屏（Transition 包裹）
```

- 建议高度范围：折线图/柱状图 300-400px，饼图/水平柱状图 250-350px
- 暗黑模式：图表背景继承卡片背景色（透明），不设独立背景色

### 7.3 图表类型

| 图表类型        | 适用场景               | 数据特征             |
| --------------- | ---------------------- | -------------------- |
| 折线图          | 时间趋势（日/月）      | 连续时间序列         |
| 柱状图          | 分组对比、实际 vs 预算 | 2-3 组对比           |
| 饼图/环形图     | 结构占比               | 一级科目占比         |
| 水平柱状图      | 明细排行、偏差排序     | 多行明细（Top 5-15） |
| 堆叠柱状图      | 构成变化               | 时间 + 构成          |
| 树图（treemap） | 分层占比               | 多级分类             |
| 表格矩阵        | 交叉维度（平台×科目）  | 二维交叉数据         |

### 7.4 ECharts 配置约定

| 元素      | 亮色                  | 暗色      |
| --------- | --------------------- | --------- |
| axisLabel | `#687385`             | `#b0b8c8` |
| splitLine | `#edf0f5`             | `#2d3748` |
| 蓝色系列  | `#1f78d1` / `#2563eb` | `#60a5fa` |
| 图例文字  | `#687385`             | `#b0b8c8` |

- 禁止 3D 图表、无业务含义的渐变色、过度动画
- 柱状图圆角：`borderRadius: [4, 4, 0, 0]`
- 饼图 label 保持在图表外（`label: { position: 'outer' }`）

### 7.5 图表空态

- 无数据时显示中文引导文案，不留下空白区域
- 文案示例："当前筛选条件下暂无数据，请调整筛选条件后重试"
- 加载中显示骨架屏而非空白

## 8. 筛选器

### 8.1 通用筛选栏布局

筛选栏是页面最重要的交互入口，布局必须严格统一：

```
┌──────────────────────────────────────────────────────────┐
│ [时间选择器] [下拉1] [下拉2] [下拉3] [主操作按钮]   [本月/本年] │
└──────────────────────────────────────────────────────────┘
```

- 容器：`flex items-center gap-3`（禁止 `flex-wrap`、禁止 `overflow-x-auto`）
- 所有控件 `size="large"`
- 固定宽度或 `flex-1 min-w-[XXXpx]` + `shrink-0`
- 时间选择器最左边，主操作按钮在筛选条件之后
- 「本月/本年」按钮组靠右（`ml-auto`）
- **绝对禁止 `overflow-x-auto`**：Element Plus 下拉菜单用 fixed 定位，父容器 overflow 会裁切弹出框

### 8.2 筛选条件排列顺序

1. 时间（月份范围选择器）
2. 费用归属/指标类型（运营费用/公共费用，净销售额/净销售件数）
3. 平台
4. 品类
5. 管控部门
6. 其他低频条件

### 8.3 快捷时间按钮

- 总览页保留"本月/本年"快捷切换
- 按钮组在筛选栏最右侧（`ml-auto`）
- 选中态：`type="primary"`

### 8.4 条件互斥

- 平台和部门互斥：选择具体平台时部门禁用，选择具体部门时平台禁用
- 公共费用模式下平台禁用

### 8.5 移动端

- `sticky top-23 z-50` 在移动端变为 `static`（不固定）
- 筛选条件过多时允许折叠或转为弹出面板
- 不得通过水平滚动容纳所有条件

## 9. 抽屉与弹窗

### 9.1 抽屉用途

| 场景                       | 方式                        | 宽度        |
| -------------------------- | --------------------------- | ----------- |
| 详情查看（任务、偏差诊断） | `el-drawer direction="rtl"` | `400px`     |
| 每日取值验证详情           | `el-drawer direction="rtl"` | `460px`     |
| 提交分析/措施              | `el-drawer direction="rtl"` | `400px`     |
| 数据来源详情               | `el-drawer direction="rtl"` | `460-480px` |

### 9.2 抽屉内容结构

```
┌────────────────────────────────┐
│ 标题              [关闭]       │  → drawer title
├────────────────────────────────┤
│ 诊断结论（amber 背景区块）      │  → 摘要判断
├────────────────────────────────┤
│ 当前项摘要（灰色背景区块）      │  → 关键字段（grid-cols-2）
├────────────────────────────────┤
│ 详细内容 / 操作表单             │  → 主要交互区域
├────────────────────────────────┤
│ 底部操作区                     │  → 提交 / 保存 / 取消
└────────────────────────────────┘
```

### 9.3 弹窗用途

| 场景     | 方式             | 说明                     |
| -------- | ---------------- | ------------------------ |
| 短确认   | `el-message-box` | 删除、关闭、归档确认     |
| 轻量编辑 | `el-dialog`      | 简单表单编辑             |
| 复杂流程 | 整页或抽屉       | 三步以上工作流不塞入弹窗 |

### 9.4 关闭与未保存

- `:before-close` 处理未保存状态
- 禁止用户误关闭导致已填写内容丢失（除非内容已保存）
- 关闭后恢复父页面滚动位置

## 10. 状态与反馈

### 10.1 状态表达映射

| 状态     | 视觉表达                                           | 业务场景               |
| -------- | -------------------------------------------------- | ---------------------- |
| 加载中   | 骨架屏（`skeleton-shine`）+ `content-fade-in` 过渡 | API 请求中             |
| 空数据   | `ArtEmptyState` + 完整中文引导文案                 | 无返回数据             |
| 空预算   | 显示 `无预算`，不计算偏差                          | 预算未录入             |
| 待接入   | 保留模块位置，标注说明                             | 后端 API 未就绪        |
| 无权限   | 页面不可见或按钮禁用 + 提示                        | 角色权限不足           |
| API 错误 | 错误提示 + 重试按钮（不要静默转为空态）            | 网络或服务异常         |
| 成功     | 短提示或下一页自动展示                             | 操作完成               |
| 警告     | `bg-amber-50 border-amber-300 text-amber-800`      | 需关注但不紧急         |
| 严重     | `bg-red-50 border-red-300 text-red-900`            | 超阈值、逾期、数据缺失 |

### 10.2 关键差异规则

| 展示值   | 含义            | 判断来源                          |
| -------- | --------------- | --------------------------------- |
| `0`      | 真实业务值为零  | API 明确返回有效的 0              |
| `--`     | 不适用或不可计算 | 后端状态或字段契约                |
| `无数据` | 当前没有可展示的数据 | API 返回为空或明确无数据状态      |
| `无预算` | 当前没有有效预算基准 | 以 docs/03 或后端返回状态为准     |

DESIGN.md 不负责判断数值 `0` 是否代表无预算。该语义必须由业务口径、字段契约或后端状态明确，前端不得自行推断。

### 10.3 骨架屏

- 优先使用全局 `.skeleton-shine` 动画（`tailwind.css` 中定义）
- 骨架形状应与实际内容布局相同（柱状/条状/矩形模拟图表）

## 11. 响应式

### 11.1 桌面端（> 1024px，验收基准 1440px）

- 完整筛选栏（sticky）
- 多列指标卡（grid-cols-4/5）
- 并列图表（2-3 列）
- 右侧抽屉叠加在工作区上方

### 11.2 平板端（768px–1024px，验收基准 1024px）

- 筛选栏保持 sticky
- 指标卡减少列数（grid-cols-2）
- 双图表转单列（`lg:grid-cols-1` → 等价于单列）
- 抽屉宽度保持不变

### 11.3 手机端（< 768px，验收基准 390px）

- 筛选栏转为 `static`（取消 sticky）
- 指标卡单列（`max-sm:grid-cols-1`）
- 图表：`min-h-[250px] max-sm:min-h-[220px]`
- 复杂表格：横向滚动或核心列视图
- 抽屉接近全屏（`max-sm:w-full`）
- **禁止简单缩小桌面页面**。内容密度应降低，优先展示结论、关键指标和异常

### 11.4 通用规则

- 所有多列 grid 布局必须配移动端回退：`grid-cols-1 sm:grid-cols-2 lg:grid-cols-N`
- 禁止 `style="grid-template-columns: ..."` 无移动端回退
- 禁止 `style="width: Npx"`（用 `class="w-[Npx]"`），或配 `max-sm:w-full`

### 12.1 标准 Token 映射

| 元素     | 亮色               | 暗色                   |
| -------- | ------------------ | ---------------------- |
| 卡片背景 | `bg-white`         | `bg-gray-900`          |

| 描述文字 | `text-gray-500`    | `text-gray-400`        |

| 表格边框 | `border-gray-200`  | `border-gray-700`      |

### 12.2 ECharts 暗色

页面、Element Plus 组件和 ECharts 图表必须随系统主题切换正确适配暗黑模式，确保背景、文字、边框、悬浮态和状态色可读。

## 13. 页面模式

以下是从现有页面中提炼的稳定页面模式。新增页面应优先匹配最接近的模式。

### 13.1 总览页模式

**适用页面：** 收入总览、费用总览、月度经营总览（部分）

**结构顺序：**

```
筛选 → 口径/预警提示（可选） → KPI 卡片 → 趋势+结构图表 → 健康矩阵/关注事项
```

**核心特征：**

- 第一屏展示最关键的经营结论（KPI）
- 图表回答"趋势如何"和"结构如何"
- 矩阵/关注事项引导用户从概览进入分析
- 所有模块在筛选切换后同时刷新
- **禁止滥用：** 不要把总览页变成全部分析功能的入口聚集页

### 13.2 差异分析页模式

**适用页面：** 费用执行偏差、收入达成分析

**结构顺序：**

```
筛选 → 偏差摘要 → 趋势/归因 → 明细列表 → 诊断抽屉/分析抽屉
```

**核心特征：**

- 左侧或上方展示问题清单（一级科目列表）
- 选中后主区域展示详情（趋势 + 多维度归因 + 二级明细）
- 右侧或抽屉内完成分析操作（提交解释/措施）
- 提交后数据进入经营事项工作台
- **禁止滥用：** 不要重复展示总览页已有的 KPI 卡片

### 13.3 利润分析页模式

**适用页面：** 利润看板

**结构顺序：**

```
筛选 → 口径提示 → 利润摘要 KPI → 趋势+归因 → 构成/瀑布图
```

**核心特征：**

- 三面板切换（净利润/运营利润/营业利润）
- 环同比分析 + 利润构成瀑布图
- 品类/平台利润排行
- 无核算数据时显示提示信息而非全 0

### 13.4 经营工作台模式

**适用页面：** 经营事项工作台

**结构顺序：**

```
筛选 → 角色图例 → 待处理列表/看板 → 详情抽屉 → 操作（分派/复核/催办/归档）
```

**核心特征：**

- 三视图切换：财务处理、业务待办、月会汇报
- 每个视图有自己的 KPI 统计卡片
- 主要交互在右侧抽屉内完成
- 列表点击 → 详情抽屉 → 操作确认 → 列表刷新

### 13.5 数据管理页模式

**适用页面：** 数据状态与覆盖、数据接入中心、每日取值验证

**结构顺序：**

```
顶部导航栏（SubNav） → 状态概览 → 详情列表/接入流程 → 异常处理（抽屉/弹窗）
```

**核心特征：**

- 多个子路由共用布局容器（`<router-view>` + SubNav 切换）
- 以数据状态而非分析结论为主要展示内容
- 操作与展示分离（状态展示为主，操作为辅）
- 财务核对流程有独立的状态流转（待核对→待处理→待复核→已确认）

## 14. Do / Don’t

### Do ✅

- 优先复用现有公共模式（指标卡、筛选栏、图表容器、抽屉结构）
- 异常和待处理事项比正常状态更醒目
- 表格、图表和指标卡显示完整的单位（万元、%、pct）
- 跨页面保持术语、状态色和筛选顺序一致
- 为加载、空态、错误和待接入提供明确的视觉反馈
- 金额列使用 `tabular-nums` 确保数字等宽对齐
- 所有可交互元素提供 `hover` 反馈和 `focus-visible` 焦环

### Don’t ❌

- 不滥用渐变、玻璃拟态、大阴影和无业务含义的动画
- 不让所有页面都变成相同尺寸的卡片集合——不同页面应有不同的布局密度和层级
- 不自行增加原型或需求中不存在的页面模块
- 不使用颜色作为唯一的表达手段——颜色必须配合文字说明
- 不将 mock 数据、原型中的示例数字和临时文案照搬到实现中
- 不引入第二套 UI 组件体系（当前稳定体系：Element Plus + ECharts + Tailwind CSS）
- 不把当前某个组件的偶然实现提升为全局规范（区分"稳定的模式"和"历史的实现细节"）
- 不混淆 `0` / `--` / `无数据` / `无预算` / `待接入` 的展示语义
- 不把多个页面共用的 ECharts 配色在每个组件中重复定义——统一使用 §3.10 的规范值
- 不在 DESIGN.md 中写入 ECharts 或 Vue 的初始化、销毁、监听、重绘等工程实现细节——这些不是设计规范

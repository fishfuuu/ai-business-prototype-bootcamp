LLM (大语言模型)
核心引擎
基于 Transformer 架构在内存中推演概率序列的语言预测模型，本身没有任何操作系统读写物理句柄。必须通过宿主程序暴露的 Tools 工具才能操作物理世界。
🚫 避免误用: 全知全能AI, 智能黑盒
Tools (工具接口)
物理手脚
由宿主程序暴露给 Agent 的受控 API / 函数（如物理文件读写、终端运行命令），是 Agent 操作磁盘与系统环境的受控物理手脚。
🚫 避免误用: AI 自发功能, 插件黑盒
Agent (受控执行者)
协作实体
以 LLM 为核心控制器、提示词与规则为物理约束、Tools 为操作介质，能够在明确目标下组织多步行动的受控软件实体。
🚫 避免误用: 自动化脚本, 机器人
ReAct 范式 (Reasoning & Acting)
架构范式
Reasoning and Acting 闭环。Agent 每次行动后，将 Observation（工具返回值、终端编译报错或日志）送回 LLM 内存进行自修正与下一步推理。
🚫 避免误用: 盲目试错, 自动改错
HITL (人在回路授权门禁)
安全防错
Human-in-the-Loop。要求 Agent 在修改物理代码、落盘写盘或发布前暂停自动化，交由人类主管审批盖章签署口令的物理控制机制。
🚫 避免误用: 人工客服, 机器弹窗
Mock Data (模拟数据)
数据安全
符合业务结构契约但内容完全虚构的数据道具，用于原型演示，严禁带入真实的客户隐私、财务或生产敏感数据。
🚫 避免误用: 真实测试数据, 生产数据
试衣镜 (127.0.0.1)
预览体验
运行于本地开发服务器（如 Vite / Node.js）的前端预览窗口，用于主管实时肉眼校验 Agent 渲染的页面外观与交互行为。
🚫 避免误用: 线上生产环境, 测试服务器
Design Token (设计令牌)
视觉规范
在设计规范文件（DESIGN.md）中事先约定的标准化视觉变量（如主色、字号标尺、间距、圆角），用于制衡 AI Token 的随机性。
🚫 避免误用: 随机内联样式, ad-hoc 杂色
Grill-Me 追问范式
需求解构
使用反向面试的思考路径，唤醒 grill-me Skill 护栏让 Agent 主动扮演考官，结构化追问并锁死 Goal / Boundary / Risk / Stop 等 6 大业务要素。
🚫 避免误用: 模糊需求, 凭空脑补
Data Contract (数据契约)
IT 交接
在物理写界面代码前落盘的标准化 BUSINESS_FEATURE_CARD.md 功能卡与 TypeScript 接口类型草稿 (`contract.d.ts`)，确保 UI 与未来 IT API 零缝隙无损对接。
🚫 避免误用: 随机内联字段, 临时假数据
Working Tree (工作区 / 工作树)
Git 工程
开发者或 AI 正在修改代码、做切片物理写盘的文件夹区域。类似于厨师切菜的“砧板”，未改动时为 Clean，有改动时为 Dirty。做完切片随时打包归档恢复 Clean 干净状态。
🚫 避免误用: 缓存目录, 临时文件区
Plan & Execute 增量范式
受控循环
将大需求拆解为包含具体文件路径与状态机的 IMPLEMENTATION_PLAN.md 实施计划，每次仅授权 Agent 完成一个可验证薄切片的小成功路径。
🚫 避免误用: 巨石盲开, 一口气改全盘
CLAUDE.md 工程规约
最高护栏
项目根目录下的最高行为规范文件，AI 每次对话前强制读取，用于物理锁死包管理器（npm）、禁用未经授权第三方包与 Vite 配置文件隔离红线。
🚫 避免误用: 口头规则, 临时说明文档
三分记忆模型 (Three-Layer Memory)
记忆管理
解耦为工作记忆（聊天窗口: 随用随清）、外部长期记忆（Markdown 文件与实施计划: 跨会话继承）与版本证据（Git Commit 节点: 物理追溯与 S/L 读档）的三层记忆体系。
🚫 避免误用: 依靠聊天记录记忆
S/L 存档还原机制 (Save & Load)
基线保护
通过 Git Commit 进行稳定存档（Save），当 Agent 产生严重幻觉或改坏工程配置时，下发指令一键撤销并读档还原（Load）至最近的干净 Commit 基线。
🚫 避免误用: 在破损代码上继续试错
五层诊断卡 (Five-Layer Diagnostic Map)
排错拓扑
物理拆解为环境层、数据源层、组件状态层、日志层与契约断言层五层口语化诊断拓扑（汽车诊断仪 🚗），精准定位 Bug 物理层级。
🚫 避免误用: 盲目试错, 控制台恐慌
事实锚定排错 (Fact-Anchored Loop)
验证闭环
修改代码前强制建立物理可测的 PASS/FAIL 验证信号，日志脱敏敏感 Key (``)，并将五层结论物理落盘写入 `LESSON_06_DEBUG_REPORT.md`。
🚫 避免误用: 粘贴敏感 Token 抓包, 无断言盲改
2 轮硬熔断机制 (Checkpoint Breaker)
安全保护
排错前下发 Checkpoint 无痛存档 (Save Point)，当 Agent 自修 2 轮仍未 PASS 时，自动触发 `git restore .` 安全恢复 Checkpoint 干净状态并导出补丁。
🚫 避免误用: 盲目死循环修复, 越改越崩白屏
QA Subagent (QA 子智能体)
测试沙箱
受主 Agent 调度的只读沙箱子进程（.claude/agents/qa-tester.md），协同 Playwright 与 Chrome DevTools 双 MCP 执行质量测试，完结后自动销毁沙箱。
🚫 避免误用: 口头凭空承诺, 污染主开发Context
双 MCP 工具链 (Dual MCP Tooling)
双端审计
由 Playwright MCP（DOM 慢动作交互与照片截图）与 Chrome DevTools MCP（Console 0 报错与 127.0.0.1 网络白名单）构成的多维自动化测试工具链。
🚫 避免误用: 单一静态截图, 忽略运行报错
四类证据链与验收总卡 (Evidence Chain & Index)
交付落盘
由视觉照片 (`screenshot.png`)、行为脚印 (`action.log`)、工程体检 (`typecheck.log`)、范围存根 (`diff.patch`) 及带 Header 的 `LESSON_07_EVIDENCE_INDEX.md` 构成的全方位客观审计交付包。
🚫 避免误用: 嘴巴口头验收, 无落盘物证交付

Lesson 02 · 视觉 Harness 与事实锚定

用参考图与设计规则做出像样的页面
Token、多模态与视觉重构

🎯 本课目标：不要用口头凭空描述 UI！学会用多模态能力提取参考图布局，利用 DESIGN.md 控制颜色与 Token，并在改崩时使用 Git 节点与 Discard Changes 1 秒无损恢复。

01 本课背景与核心原理

记住核心法则：
自然语言描述“要高端大气”极易导致 UI 崩溃。通过上传参考图（多模态提取）+ 挂载 DESIGN.md 视觉 Harness + Git SL 存档大法，实现 100% 受控界面美化。

02 💡 本课 4 大核心工程概念卡

⏱️ 核心概念 1：Token 与 Context 上下文窗口

1. 硬核工程定义LLM 处理文本代码的物理计算单位（约0.75个英文单词），以及单次会话可保持注意力的最大内存上限。
2. 底层运作机制AI 每次读写均消耗 Token；Context 积压过多会稀释注意力，引发规则幻觉。
3. 具象业务比喻高考试卷的答题卡与计时器 ⏱️。答题卡格子有限，写满后必须定期清理草稿。
4. IT 沟通场景“样式改动需控制 Token 消耗，避免 Context 窗口过大导致 AI 遗忘。”

📸 核心概念 2：多模态视觉提取 (Multimodal Visual Extraction)

1. 硬核工程定义LLM 联合解析文本与图像像素阵列的能力，将参考截图转化为结构化 DOM 代码的范式。
2. 底层运作机制分析输入参考图的盒模型与排版，将其映射为 Vue 模板代码与 CSS 类。
3. 具象业务比喻建筑设计师的现场测绘拍照 📸。看到精装房拍照，直接在图纸上按比例复刻硬装结构。
4. IT 沟通场景“我们利用多模态视觉提取能力，直接从参考图中提取了工单看板布局。”

🧱 核心概念 3：视觉 Harness (DESIGN.md) 与 tailwind.css 字典映射

1. 硬核工程定义根目录下的视觉规范契约，结合 src/assets/styles/tailwind.css 运行时物理文件。
2. 底层运作机制在 `DESIGN.md` 声明 Token，在 `tailwind.css` 声明 `var(--art-primary)` 色值。
3. 具象业务比喻乐高积木的标准规格颗粒与品牌字典 🧱。修改一处 `var(--art-primary)` 全站自动变色。
4. IT 沟通场景“界面样式受扣于 DESIGN.md，全站一处改色即可全局自动升级。”

🎮 核心概念 4：Git 节点安全防护与 Discard Changes (SL 游戏存档大法)

1. 硬核工程定义通过显式 Git 提交冻结镜像，并利用 GUI 进行文件级的无损变更撤销。
2. 底层运作机制`git commit` 生成哈希快照；`git diff` 对比装备属性；`git discard` 一键读档 Load。
3. 具象业务比喻代码界的 SL 游戏存档大法 (Save & Load) 🎮：Git Commit 相当于存档 Save，Git Discard 相当于 1秒读档 Load！
4. IT 沟通场景“每次重大重构前建立 Git 稳定节点，支持 Discard Changes 安全物理回滚。”

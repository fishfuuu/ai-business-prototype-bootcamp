Phase 2

Phase 3

二分定位与契约隔离

排错范围严格限定在 prototype-contract.d.ts 契约层与界面呈现，禁止深挖 Vue/Vite 底层包。

Phase 4

修补限定在契约层。若 2 轮自修未 PASS，自动触发 git restore . 安全恢复 Checkpoint 状态。

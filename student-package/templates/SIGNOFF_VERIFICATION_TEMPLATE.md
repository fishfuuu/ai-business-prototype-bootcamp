# 签发前核验与裁决单 (Pre-Signature Verification & Sign-off Form)

> **使用指引**：本表单供业务主管在对任何上报材料、对外声明、考核结论、跨部门说明等结论性文件执行“签字/批准/放行”动作前使用。**落笔签字即代表主管对材料真实性背书。** 严禁凭“下属口头保证”或“Agent 声称核过了”直接签字；必须先由 Agent 出具物证核验底稿，经主管抽查核准后方可作出最终签发裁决。

### 5. 最终签发裁决 (Sign-off Verdict)

主管依据客观物证核验底稿，对本份材料作出如下裁决（三选一）：

- [ ] **【同意放行 (APPROVED)】**：材料所有核心表述均有确凿物证支持，同意签字放行。
- [ ] **【修正后放行 (APPROVED WITH REVISIONS)】**：剔除/修正上述存疑清单中的不实说法，并补全物证后准予放行。
- [ ] **【坚决打回 (REJECTED)】**：材料存在重大虚构或关键事实与物证严重背离，退回重做并启动流程问责。

## 四、 生产就绪差距清单 (Production Gap Analysis)

*诚实列出原型与生产环境的真实差距，不甩锅、不粉饰：*

| 维度 | 原型样板间实现方式 | 生产系统必要改造需求 | 建议 IT 建设方案 |
| :---: | :---: | :---: | :---: |
| **数据源** | 本地静态 Mock JSON / CSV | 企业级真实数据库 (MySQL / PG) | 由 IT 统一设计表结构与读写分离 |
| **鉴权与权限** | 前端写死单一角色查看 | 企业统一 SSO / RBAC 细粒度权限 | 接入企业 LDAP / OAuth 体系 |

| **AI 接口通道** | 原型抽屉组件模拟调用 | 企业内网私有网关与统一鉴权 | 走内部大模型网关统一管理 Token |

### 一、 价值与契约审查 (Pass / Fail)
- [ ] **功能专注度**：是否只解决一个明确的业务问题，而非包罗万象的大杂烩？
- [ ] **输入契约清晰**：是否明确说明了需要提供什么格式的数据（如 CSV / JSON / 纯文本）？
- [ ] **输出格式可控**：其输出物是否具备固定的表格或结构，能够直接肉眼核验？

### 二、 安全与红线审查 (全勾选方可放行，任一不符一票否决)
- [ ] **权限只读性**：该 Skill 是否仅做数据读取与分析？（若涉及删除/篡改源文件、执行未经说明的系统脚本，一票否决！）
- [ ] **敏感数据本地脱敏**：是否在本地完成客户隐私、员工个人信息、银行卡号等字段的脱敏/截断/打码后再投喂？（严禁将明文真实敏感数据直接喂入 LLM，一票否决！）
- [ ] **网络与数据不出境**：代码或 SOP 中是否存在未经授权向外部不可信第三方域名/服务回传数据的动作？
- [ ] **无破坏性命令**：技能内容与调用链中是否绝对不含 `rm`、`format`、`drop`、破坏性写等高危破坏性指令？

### 三、 主管放行裁决
- [ ] **APPROVED（批准引入）**：可在部门 Agent 中挂载使用。
- [ ] **REJECTED（拒绝引入）**：存在安全风险或功能模糊，禁止安装。

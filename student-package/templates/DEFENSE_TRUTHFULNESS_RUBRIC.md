## 二、五维求真评审标准

| 评审维度 | 权重 | 核心考核要点与硬指标 | 得分 (1–5分) / 判定 | 评委现场核验意见 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 已证实范围证据链** | 25% | - 是否清晰界定原型在沙盘中的已验证范围；<br>- 是否显式引证 L3 契约、L7 浏览器截图、L8 Codex Finding 或 L9 实测日志；<br>- 是否严禁将 Mock 模拟或静态假数据冒充为“真实已证实能力”。 | [ ] 5分：物证链闭环完备<br>[ ] 3分：有物证但引证模糊<br>[ ] 1分：无物证或将Mock当证实 | |
| **2. 生产差距诚实暴露** | 25% | - 是否诚实交代原型与生产系统之间的真实工程差距（八大门禁：真实数据库、网络鉴权、并发容灾、监控回滚等）；<br>- 通道 1 是否明确附带“非生产代码声明”；通道 2 是否列出本地依赖表；<br>- 严禁宣称“代码已生产就绪可直接全网部署”。 | [ ] 5分：差距坦诚透彻<br>[ ] 3分：列出部分技术差距<br>[ ] 1分：隐瞒缺口或宣称上线 | |
| **3. 非目标与红线界定** | 20% | - 是否明确圈定本期“坚决不做”的非目标清单；<br>- 是否指出至少 1 个“坚决拒绝 AI 介入”的高危法定义务或资金环节；<br>- 是否为关键 AI 节点设立强制人在回路（HITL）审批门禁与熔断规则。 | [ ] 5分：红线刚性门禁严密<br>[ ] 3分：有红线但缺少门禁<br>[ ] 1分：全自动流转无红线 | |
| **4. 周一试水落地规程** | 20% | - 是否交代下周一在部门工位日常小规模安全试水的具体规程；<br>- 是否明确具体试点工位、输入数据脱敏规约与人工终审机制；<br>- 是否指派了真实具体的第一责任人（Owner，含姓名与岗位），严禁留空。 | [ ] 5分：工位/脱敏/Owner三齐备<br>[ ] 3分：缺少明确Owner或脱敏<br>[ ] 1分：无落地计划空谈理论 | |
| **5. 虚夸 ROI 一票扣分项** | **一票否决 / 扣分** | - **一票否决红线**：凡在汇报中出现“每周节省 X 小时”、“全自动替代 X 个人”、“每年降本数百万元”等毫无严谨测算依据的商业大饼词句，本项直接判定为【违规】；<br>- 违规者当场打回讲稿，扣除总分 30 分，并勒令当场删除浮夸词句重新陈述。 | [ ] 合格：求真务实零吹嘘<br>[ ] 违规：触碰虚假ROI红线（扣30分并当场纠偏） | |

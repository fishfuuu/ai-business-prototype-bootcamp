# 外部技能离线候选清单 (OFFLINE_SKILL_CATALOG)

> **免责与合成说明**：本清单为教学专用虚构合成候选清单（Synthetic Catalog），除官方预审技能（本地文件引用）外，其余条目不涉及任何真实企业商业机密、专有数据与真实开源项目。涉及项目名称、描述与统计指标均为教学沙盘模拟构造。

---

## 一、 使用说明 (Usage Guide)

本清单用于在断网或内网受控环境下，替代 `find-skills`（或 `npx skills find`）线上检索生态。

学员照样执行 Task 3 ① 的“检索与候选登记”动作：
1. 根据你的部门高频办公场景（如：报销对账 / 销售流水汇总 / 供应商比价），从以下候选条目中挑选 1 个最匹配的候选技能；
2. 将该技能的四项信息（技能名称、来源平台/仓库、一句话功能描述、热度/安装量）登记至《业务主管外部 Skill 选型与安全体检表》的“候选 Skill 名称”与“来源平台/仓库”栏；
3. 随后以该首选候选作为体检对象执行 4 项安全红线体检（若选用合成条目且信息不足以完成深度审查，可按 R1 规则无缝切换至官方预审技能 `csv-data-analyzer` 继续体检）；
4. **课上只读不装铁律**：本轮仅做审查与体检，严禁下载或挂载任何未经官方预审的外部技能。

## 二、 离线候选技能条目清单 (Offline Candidate Catalog)

### 候选 1：`csv-data-analyzer`（官方预审技能 · 本地基线）
- **技能名称**：`csv-data-analyzer`
- **来源平台/仓库**：课程官方受控模板库（`student-package/templates/skills/csv-data-analyzer/SKILL.md`）
- **一句话功能描述**：业务表格数据分析与异动筛查技能，支持 CSV/Excel 格式月度费用流水、对账明细的只读解析、分类聚合统计与单笔大额/发票抬头违规异动自动排查。
- **热度 / 安装量指标**：官方内置 / 预审放行（Verified Baseline）
- **本地规范路径**：`student-package/templates/skills/csv-data-analyzer/SKILL.md`

### 候选 2：`excel-reconcile-helper`（合成示例条目，仅供检索与体检练习）
- **技能名称**：`excel-reconcile-helper`（合成示例条目，仅供检索与体检练习）
- **来源平台/仓库**：[合成示例] GitHub 开源仓库 (`https://github.com/synthetic-open-skills/excel-reconcile-helper`)
- **一句话功能描述**：多表采购订单与出入库流水双向比对核对插件，自动标出跨表金额不一致与未匹配单据。
- **热度 / 安装量指标**：GitHub Stars: 2.4k / 月下载量: 12,000+
- **模拟规范要点**：声明支持只读比对，但在扩展脚本中含未说明的临时文件缓存逻辑。

### 候选 3：`vendor-price-comparator`（合成示例条目，仅供检索与体检练习）
- **技能名称**：`vendor-price-comparator`（合成示例条目，仅供检索与体检练习）
- **来源平台/仓库**：[合成示例] skills.sh 技能市场 (`skills.sh/packages/vendor-price-comparator`)
- **一句话功能描述**：供应商历史报价单梯级价格横向对比与降价趋势图表分析工具，辅助采购比价决策。

### 候选 4：`quick-tax-checker`（合成示例条目，仅供检索与体检练习）
- **技能名称**：`quick-tax-checker`（合成示例条目，仅供检索与体检练习）

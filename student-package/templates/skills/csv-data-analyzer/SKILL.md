# 业务表格数据分析与异动筛查执行手册 (csv-data-analyzer)

## 1. 业务背景与角色定位
- **使用者角色**：业务部门主管 / 运营主管 / 财务初审员
- **触发场景**：收到月度费用明细、采购流水、对账表格（如 `monthly_expense_sample.csv`）需要进行快速汇总与异常筛查时
- **业务价值**：替代手动逐行核算，5 秒内完成全量数据只读解析、分类聚合统计与高危异动标红，提升日常工位表格审计效率

## 2. 前置输入契约 (Input Contract)
在执行分析前，必须确认用户提供了以下数据，缺失任何一项必须主动暂停索取，严禁自行编造：
- **材料 1**：待分析的脱敏结构化表格文件路径或内容（CSV 或 Excel 格式，包含：单号、日期、部门、申请人、科目类别、金额、状态等字段）
- **材料 2**：核查基准参数（如：单笔高额关注阈值、重点监控部门或特定科目要求；未指定时默认按 5000 元作为高额异动线）
- **安全前置约束**：严禁分析未脱敏的真实个人隐私（身份证、银行卡全号、家庭住址），若发现必须在本地脱敏后再行喂入

## 3. 分步标准作业流程 (SOP Execution Steps)
请严格按以下四步逐步执行，严禁跳步：
1. **第一步（数据结构与完整性解析）**：
   - 检查文件行数、字段列名与数据类型；
   - 校验是否存在空值（NaN）、负数金额或日期格式非法记录。
2. **第二步（多维度聚合汇总统计）**：
   - 计算全表总笔数、总申报金额、平均单笔金额与最大单笔金额；
   - 按“部门”聚合统计各自申报总额与占比；
   - 按“费用科目/类别”聚合统计前三大开销流向。
3. **第三步（业务规则与异动排查）**：
   - 过滤单笔金额 ≥ 设定阈值（默认 5000 元）的高额支出项目；
   - 检索“发票抬头”非公司全称、“状态”为待初审或异常的记录；
   - 检索相同申请人在相邻日期内的连续单据或异常高频报销。
4. **第四步（提炼关键发现与管理洞察）**：
   - 提炼 3 条事实支撑的经营管理发现（如：某部门差旅占比过高、特定大单缺少说明等）。

## 4. 业务红线与人在回路门禁 (Guardrails & HITL)
- **只读操作铁律**：严禁 Agent 篡改、覆盖或删除源 CSV 文件；所有分析结果必须以独立报告形式呈现；
- **禁止自行平账**：如发现借贷不平或金额不符，只能如实记录并在异常清单中警示，严禁编造调整项平账；
- **强制人在回路 (HITL)**：
  - 单笔金额 ≥ 5000 元的支出；
  - 标记有“异常”、“个人抬头”或未通过初审的条目；
  - 必须归入《人工复核专区》，由主管签字确认后方可进入下一步。

# 财务发票与报销单据合规初审标准执行手册

## 1. 业务背景与角色定位
- **使用者角色**：财务报销初审员 / 部门费用把关主管
- **触发场景**：收到员工或供应商提交的月度报销明细表、发票流水清单时
- **业务价值**：自动阻断抬头不符、连号异常、单日超标等合规风险，提升报销初审效率 80%

## 2. 前置输入契约 (Input Contract)
在执行分析前，必须确认用户提供了以下数据，缺失任何一项必须主动暂停索取，严禁自行编造：
- **材料 1**：报销明细数据表（CSV 或 Excel 格式，包含：单号、日期、申请人、科目、金额、发票号、发票抬头）
- **材料 2**：公司当前执行的标准报销制度参数（如：单日差旅住宿标准上限、是否允许个人抬头发票）

## 3. 分步标准作业流程 (SOP Execution Steps)
请严格按以下四步逐步排查，严禁跳步：
1. **第一步（完整性与格式核验）**：核对每一笔记录的金额是否为大于 0 的数值，单号与发票号是否缺失。
2. **第二步（发票抬头刚性校验）**：检查发票抬头是否与公司法人全称一致。凡显示“个人”、空白或其他抬头的，必须标红拦截。
3. **第三步（差旅与科目标准比对）**：
   - 国内差旅住宿：单日上限不超过 800 元，超出部分标记超标金额；
   - 商务招待餐饮：单笔超过 1000 元必须检查是否附有陪同人员说明。
4. **第四步（发票连号与重复防范）**：检查同申请人、同一天是否存在发票号连续（如 INV-992014 与 INV-992015）或重复的情况，提示疑似拆单风险。

## 4. 业务红线与人在回路门禁 (Guardrails & HITL)
- **绝对禁止修改原始数据**：严禁 Agent 擅自修改表格中的任何金额、单号或文字；
- **强制暂停门禁 (HITL)**：
  - 一旦发现发票抬头为“个人抬头”或疑似伪造抬头；
  - 单笔报销金额超过 5000 元人民币；
  - 必须立即输出警报并强制暂停自动流转，要求主管亲自盖章审批。

## 5. 标准输出格式契约 (Output Format)
无论分析结果如何，必须严格按以下结构化 Markdown 输出：

### 一、 审核结论概览 (PASS / WARNING / BLOCKED)
- **处理总笔数**：[X] 笔
- **合规放行笔数**：[Y] 笔
- **异常拦截笔数**：[Z] 笔
- **整体风险定级**：[低风险放行 / 存在合规瑕疵 / 存在阻断性违规]

### 二、 异常明细核对清单
| 费用单号 | 申请人 | 费用科目 | 申报金额 | 异常类型 | 事实说明与违背条款 | 建议处置 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| EXP-xxx | 张三 | 住宿 | 980 元 | 超标 | 超出单日 800 元上限 180 元 | 剔除超额部分 |

### 三、 主管裁决选项 (HITL Decision)
请主管对上述异常项勾选裁决：
- [ ] **全部打回修改**：退回申请人补齐证明或更换合规发票；
- [ ] **特批按实际报销**：有部门总监特别批示说明，予以放行；
- [ ] **部分扣除后报销**：扣除超标部分金额后放行。

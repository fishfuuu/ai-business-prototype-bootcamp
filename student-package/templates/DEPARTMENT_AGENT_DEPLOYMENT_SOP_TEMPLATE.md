## 三、 周一安全落地“三不原则”与人在回路门禁 (HITL)

在工位日常运行 Agent 时，全员必须恪守以下**三大红线**：
1. **数据未经脱敏严禁外送**：所有输入数据中涉及客户姓名、身份证、手机号、公司核心财务密钥的，必须事前统一脱敏为 `<REDACTED>`；
2. **严禁赋予系统写操作与破坏性权限**：Agent 仅拥有信息检索、文档起草、表格分析与逻辑挑刺权限，严禁赋予其企业 ERP/OA/银行的自动确认或划款权限；
3. **人在回路一票否决权 (HITL)**：所有由 Agent 生成的报告、合同修改建议、发票拦截结论，必须经由**指定岗位员工或主管本人**核实物证后盖章确认，严禁未经复核直接对外发送。
